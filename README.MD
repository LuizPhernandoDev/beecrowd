# 🐝 Beecrowd Solutions

Repositório dedicado ao armazenamento das resoluções de desafios propostos na plataforma **Beecrowd**.

## 📈 Áreas de Estudo
- **Algoritmos Iniciantes**: Prática de entrada e saída padrão e condicionais.
- **Matemática**: Implementação de fórmulas e teoria dos números.
- **Ad-Hoc**: Simulações e problemas de lógica aplicada.

## 🛠️ Tecnologias
- Linguagem C (padrão utilizado para as submissões).
